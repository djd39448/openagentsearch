# What this is: the FIXED, committed list of rooms that index-refresh-sanity.py's `--poll-set`
# counts against, on both the new and the published liveness-v1.json, when deciding whether the
# map's "rooms classified" (class != unknown) has shrunk more than 10%. Before this file existed,
# the gate counted classified rooms across the WHOLE 38-room map; but the message-log poller

# Scoping the gate to "whatever the map currently selects" would be circular (the poller's shrink

# are simply logged (see index-refresh-run.ps1 step 3b's informational lines), never counted here.
#
# THE ONLY SANCTIONED RE-SCOPE: editing this file (adding or removing a room) is the one approved
# way to change what the gate protects. A removal that would otherwise trip the no-shrink gate
# still needs the one-shot `oas-index\ALLOW-SHRINK` marker for that run, same as any other
# intentional shrink -- ALLOW-SHRINK is not a substitute for editing this file, and this file is not
